# 旅记可视化产品文档

## 1. 产品定位

旅记可视化是一个面向朋友分享的静态旅行纪录页面。它把一次具体行程沉淀为可浏览、可交互、可重新发布的旅行路书，并为之后接入 Obsidian 和自动生成攻略保留结构化数据入口。

## 2. 用户与场景

- 主要用户：创建旅行记录的人，以及被分享链接的朋友。
- 当前场景：一次性生成并发布一趟旅行，不做复杂的在线录入系统。
- 使用方式：打开总入口地球仪，点击一个旅记，再按路线、日期和提醒浏览。

## 3. MVP 核心流程

1. 总入口展示已沉淀的旅行地点。
2. 点击挪威地点进入 13 天单次旅记。
3. 在地图上查看北线、南线和每日交通段。
4. 点击日期查看当天的行程、交通、住宿区域和提醒。
5. 在设备本地拖拽日期顺序、勾选提醒；更新后的正式版本通过重新生成页面发布。

## 4. 体验方向

旅行纪录片 + 手帐：深色夜空、毛玻璃、地图路线、卡通化地球仪、滚动进入动画和轻量交互。视觉效果服务于叙事，不替代真实行程信息。

## 5. MVP 验收标准

- 桌面端和手机端均可访问。
- 地球仪地点和旅记卡片可以进入单次路书。
- 地图可拖拽、缩放并展示公开地点与路线。
- 13 天内容可切换，9 月 26 日明确显示已锁定的 Plan A。
- 日期支持拖拽排序，提醒支持勾选，状态只保存在当前设备。
- 页面和仓库不包含个人联系方式、证件、订单号、预订凭证、原始 PDF 或私人 Obsidian 内容。
- 可作为纯静态文件直接部署到 GitHub Pages。

## 6. 非目标

- 暂不做账号体系、多人协作、在线编辑后台或数据库。
- 暂不把天气、体力和现场排队等条件性安排伪装成确定事实。
- 暂不自动抓取私人 Obsidian 知识库。
