# 地图数据来源

## 运行时底图

- MapLibre GL JS：负责 WebGL 地图渲染、缩放、拖拽、旋转、弹窗和 globe 投影。
- OpenFreeMap Liberty：免费公共矢量地图样式，数据来自 OpenStreetMap；页面保留地图归属信息。

## 本地兜底

- `data/world-countries.geojson`：Natural Earth 低分辨率国家边界数据。
- 本地数据用于公共瓦片加载较慢或暂时不可用时的稳定展示，包含海洋、陆地、国界、国家名和主要地点标签。
- 该文件只用于旅行视觉化，不替代导航、道路通行或实时交通数据。

## 设计约束

- 不接入 Google、高德、百度等需要 API Key 或计费绑定的地图服务。
- 个人和朋友小范围使用保持纯静态、无后端、无账号、无数据库。
- 页面中的具体行程标记、路线和提醒来自 `data/norway.js`，与地图底图分离，方便以后生成新的单次路书。
