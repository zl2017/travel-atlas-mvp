# 内容来源与隐私边界

## 当前内容来源

当前 MVP 依据用户提供的《挪威13天完整行程--真实版》整理。公开页面采用其中的路线、日期、地点、交通方式和行程提示，不复制原始文件本身。

## 公开内容

- 国家、城市、景点和公开路线。
- 日期、天数、交通类型和路线顺序。
- 适合朋友阅读的提醒、备选状态和公开链接。

## 不公开内容

- 原始 PDF、签证材料、预订凭证和支付信息。
- 姓名、电话号码、邮箱、证件号码和订单号。
- 私人住址、私人 Obsidian 路径和未脱敏照片元数据。
- 不必要的精确住宿地址或实时位置。

## 更新前检查

1. 搜索个人信息、订单号、证件号和本机路径。
2. 检查可选计划是否仍标注为可选，不把条件性安排写成确定事实。
3. 检查链接只指向适合公开分享的页面。
4. 确认原始 PDF 和私人知识库文件没有进入 Git 追踪范围。
