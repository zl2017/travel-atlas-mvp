# V2 设计参考与改造记录

本次 V2 参考公开旅行产品和互动地图案例的交互模式，视觉与内容仍为本项目独立实现。

## 参考得到的模式

### 1. 地图成为入口

Plot a Trip 将地图作为规划主界面，而不是行程列表旁边的一块小地图。V2 因此把路线地图提升为“路线剧场”，增加全程、北线、南线筛选和站点检查面板。

### 2. 路线与记忆绑定

Wandria 将地点、路线、照片和日记绑定在同一个旅行记忆里，并强调不同交通方式的动画路线。V2 采用编号站点、交通符号、路线颜色和 Plan A 轮渡节点，给后续加入照片和手帐内容留出位置。

### 3. 地图跟随故事推进

TraveledMap 的核心模式是日程推进时地图自动聚焦当前步骤；Mapbox 的 scrollytelling 模板则把地图视为叙事内容的一部分。V2 保留当前点击日期聚焦地图的交互，同时增加当前日路线高亮、进度条和站点面板。

## V2 做了什么

- 2.0 默认底图采用 OpenFreeMap Liberty 矢量地图，路线和标记继续使用夜间手帐风格的高对比配色。
- 为北线、南线加入双层路线：发光底线 + 动态虚线主线。
- 将圆点标记升级为带编号、交通符号和分区颜色的路线站点。
- 增加全程 / 北线 / 南线模式切换。
- 增加右侧路线检查面板，点击站点会联动到对应日程。
- 增加当前路线 HUD、当前日路线高亮和行程进度条。
- 保留手机端横向站点滚动，避免地图和信息面板在窄屏上互相挤压。

## V2.1 地理对应性修正

- 地图框架升级为 MapLibre GL JS，底图使用带署名的免费 OpenFreeMap / OpenStreetMap 矢量数据，支持连续缩放、原生地名层、拖拽旋转、缩放控件和地点弹窗。
- 稳定性兜底：仓库内置 Natural Earth 低分辨率国家边界 GeoJSON，在公共瓦片加载较慢时仍绘制海洋、陆地、国界、国家名和主要地点标签。
- 首页入口也复用同一套真实底图：挪威、Senja、罗弗敦、卑尔根、盖朗厄尔和斯德哥尔摩使用行程数据中的真实经纬度，北京作为 Home Base 标记；拖拽时外围轨道同步旋转，点击弹窗可进入对应路书。
- 关键站点保留编号大标记；每日行程中的 34 个去重坐标全部生成小型地点标记。
- 每个地点标记直接取自 `days[].map` 的经纬度，并与对应日期联动，避免出现路线经过但地图没有地点的情况。
